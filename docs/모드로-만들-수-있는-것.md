# FM24에서 「모드」로 할 수 있는 일과 할 수 없는 일

처음 요청은 "전술 조언을 해 주는 **모드**"였습니다. 결론부터 적으면, 그런 모드는
FM24에서 **기술적으로 만들 수 없습니다.** 왜 그런지, 대신 무엇을 했는지 적어 둡니다.

---

## FM24가 열어 둔 수정 경로

FM24에서 사용자가 손댈 수 있는 곳은 네 군데입니다.

### 1. 스킨 (Skin)

`Documents/Sports Interactive/Football Manager 2024/skins/` 아래 XML로 화면을 다시
그립니다. 패널을 옮기고, 색과 글꼴을 바꾸고, 기본 화면에 없는 값을 꺼내 보여 줄 수
있습니다.

**할 수 없는 것**: 계산. 스킨 XML은 게임이 이미 갖고 있는 값을 배치하는 선언일 뿐
반복문도, 조건 분기도, 함수 호출도 없습니다. "상대가 하이라인이면 공간으로 패스를
켜라"는 판단을 스킨 안에 넣을 방법이 없습니다.

### 2. 그래픽

로고·얼굴·유니폼·배경을 `config.xml`로 교체합니다. 순수하게 보이는 것만 바뀝니다.

### 3. 에디터 데이터 (`.fmf`)

공식 프리게임 에디터로 선수·구단·대회·규정을 고칩니다. 데이터베이스를 바꾸는
것이지 게임의 동작을 바꾸는 것이 아닙니다.

### 4. 인게임 에디터

별도 구매하는 도구로, 진행 중인 세이브의 값을 직접 고칩니다. 이것도 조언을 하는
물건은 아닙니다.

---

## 그래서 없는 것 — 스크립트 실행 지점

정리하면 FM24에는 **사용자 코드를 실행하는 지점이 없습니다.** 플러그인 API도,
Lua/JS 같은 내장 스크립트 엔진도, 모드가 붙을 수 있는 훅도 없습니다.
게임 안에서 매 경기 상대 전술을 읽고 계산해 조언을 띄우는 물건은, 게임을 역공학해
메모리를 직접 건드리지 않는 한 존재할 수 없습니다. 그건 모드가 아니라 치트 트레이너에
가깝고, 세이브 손상과 온라인 이용 정지 위험을 함께 가져옵니다.

전술 파일(`.fmf`)을 만들어 내는 것도 같은 이유로 접었습니다. 형식이 공개돼 있지
않은 바이너리라, 커뮤니티에서 부분적으로 해독한 결과에 기대면 패치 한 번에
깨지고 세이브를 망가뜨릴 수 있습니다.

---

## 대신 한 것

**FM 옆에 띄워 두는 도구**로 만들었습니다. 게임을 고치지 않고, 게임이 공식적으로
제공하는 내보내기로 데이터를 받습니다.

- 스쿼드는 FM의 **인쇄 → 웹 페이지/텍스트 파일** 내보내기로 가져옵니다.
  세이브 파일을 읽지 않으므로 손상 위험이 없고, 패치가 나와도 깨지지 않습니다.
- 상대 전술은 **경기 전 스카우트 보고서**를 보고 몇 번 누르면 됩니다.
- 결과는 FM 화면에 그대로 옮겨 적을 수 있게 FM이 쓰는 용어와 라벨로 나옵니다.
  「전술 텍스트로 복사」를 누르면 전부 텍스트로 나옵니다.
- 브라우저에 설치(PWA)하면 오프라인으로 열리고, 휴대폰에 띄워 두고 PC에서
  FM을 하는 식으로 쓸 수 있습니다.

바꿔 말하면 **"게임 안의 모드" 대신 "게임 옆의 도구"** 입니다. 요청하신 기능
(상대 전술에 따른 대응, 포지션별 역할, 개인 전술 조언)은 전부 들어 있고,
빠진 것은 그 결과가 게임 화면 안에 뜨지 않는다는 점뿐입니다.

---

## 화면 안에 띄우고 싶다면 — 겹쳐 보기

게임이 우리 코드를 실행하게 만들 수는 없지만, **게임 화면 위에 겹쳐 두는 것**은
됩니다. 게임을 전혀 건드리지 않으므로 위험도 없습니다. 이게 인게임에 가장 가깝습니다.

1. FM을 **창 모드** 또는 **테두리 없는 창 모드**로 둡니다
   (전체 화면 전용 모드에서는 어떤 창도 위에 뜨지 않습니다).
2. `tools/오버레이-실행.bat`(Windows) 또는 `tools/overlay.sh`(macOS·Linux)를 실행합니다.
   주소창·탭 없는 좁은 창으로 열립니다. 브라우저에서 직접 열고 오른쪽 위
   **「겹쳐 보기」** 를 눌러도 같습니다.
3. 그 창을 항상 위로 고정합니다.
   - **Windows** — [PowerToys](https://learn.microsoft.com/windows/powertoys/) 설치 후 창을 고르고 `Win + Ctrl + T`
   - **macOS** — Rectangle, BetterTouchTool 등의 Always on Top
   - **Linux** — 제목 표시줄 우클릭 → 「항상 위에」

겹쳐 보기는 경기 중에 실제로 다시 보는 것만 남깁니다 — 선발 11명의 역할과 임무,
기본값에서 바꿔야 할 지시, 핵심 대응, 점검할 점. 설명은 전부 걷어냅니다.

모니터가 둘이면 그냥 두 번째 화면에 띄워 두는 편이 제일 편합니다.

## 하지 않은 것 — 메모리 후킹

게임 프로세스에 코드를 주입해 값을 읽어 오는 방법은 기술적으로 존재합니다.
쓰지 않았습니다. 형식이 공개돼 있지 않아 패치마다 깨지고, 세이브를 망가뜨릴 수
있으며, 그 시점부터는 모드가 아니라 치트 트레이너입니다. FM 내보내기로 얻는 것과
정보량 차이도 크지 않습니다.

## 상대 전술을 게임에서 읽는 곳

이 도구의 **상대** 탭을 채울 때 FM 어디를 보면 되는지입니다.

| 채울 항목 | FM에서 볼 곳 |
| --- | --- |
| 포메이션 | 경기 전 **상대 팀 보고서 → 예상 라인업**, 또는 지난 경기 기록 |
| 멘탈리티 · 수비 라인 · 압박 | **스카우트 보고서 → 전술 성향** 요약 문장 |
| 공을 잃었을 때 / 얻었을 때 | 같은 보고서의 「역습을 노린다」 「공을 잃으면 즉시 압박」 문구 |
| 빠른 공격수 · 제공권 · 플레이메이커 | **상대 핵심 선수** 항목과 그 선수 능력치 |
| 느린 센터백 · 작은 수비진 | 예상 라인업의 센터백 속도·점프 도달력 |
| 골키퍼 배급 불안 | 상대 골키퍼의 킥·패스 |
| 약한 측면 | 지난 경기 히트맵, 또는 상대 풀백의 마크·태클 |

모르는 항목은 표준으로 두면 됩니다. 확실한 것만 넣어도 결과가 나오고,
넣은 항목은 결과 화면의 「상대 대응 전략」에 이유와 함께 그대로 나타납니다.
